# 商家费率对比工具 / Merchant Rate Comparison Tool

一个简单易用的费率对比计算器，帮助商家快速对比不同费率方案下的成本差异。

## 功能特性

- 📊 实时计算两个费率方案的成本对比
- 💰 支持按交易金额百分比 + 单笔固定费用的计算方式
- 📱 响应式设计，支持移动设备
- 🚀 无需后端，纯前端实现

## 使用方式

1. 输入月交易金额和月交易笔数
2. 设置当前费率和优惠方案费率
3. 点击"立即计算对比"按钮
4. 查看每月节省金额
